# UI Quality & Taste Polish Skill

## Emil Kowalski Design Engineering Principles
1. **Visual Hierarchy**: Guide the eye with size, contrast, and weight. Don't make everything equally prominent.
2. **Intentional Spacing**: Consistent spacing scale (4px, 8px, 12px, 16px, 24px, 32px).
3. **Smooth Transitions**: Micro-interactions with purposeful easing (150ms-200ms cubic-bezier).
4. **State Completeness**: Every card or panel must have polished Default, Loading, Empty, and Error states.
5. **Zero Clutter**: Eliminate decorative fluff that doesn't aid threat detection or situational awareness.

## Multi-Device Verification Matrix
- **Desktop (1440px)**: Multi-column SOC layout, side-by-side Live Stream & Spectrogram.
- **Tablet (768px)**: Flexible grid with collapsible sidebar.
- **Mobile (375px)**: Stacked cards, responsive touch targets (min 44px), horizontal scroll protection.
